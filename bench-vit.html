Can this phone run a big model?

The roster is 296 animals because that is all the small classifier knows. A far bigger one exists — a CLIP-style model that lets the species list be chosen rather than baked in — but it is about ten times the arithmetic. Whether that fits depends on the GPU, which the scanner is not using. These two tests measure it. Run the first one; it is quick and needs no download.

1. Raw GPU throughput

A plain matrix multiply on the GPU, and the same one on the CPU, with nothing else involved. Answers "is the GPU worth targeting at all". A few seconds, no download.

2. A real vision transformer

Downloads CLIP ViT-B/16 — the same architecture and size as the biological model worth moving to — and times one image through it on the GPU and on the CPU. About 90 MB, so do this on wifi. This is the number that decides the question.
